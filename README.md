# SalmonEngine
Chess engines made easy.

### Name origin

Since salmon return to their birthplace, this engine is sort of returning to when engines didn't use NNUEs.

### Why no NNUE?

I don't *hate* NNUEs, i just don't *like* them. They turn a chess engine into more of a black box which makes things a bit more difficult to actually understand *why* a move was chosen.
I made this project simply to allow for people to make their own chess engines without having to touch anything related to machine learning or potentially difficult to use/understand libraries.
